# 体检

给「晤 · With You」做的整套检查。**不是每次改完都跑**，定期查一次就好 ——
比如隔一两周，或者一批大改动上线之前。跟 Claude 说一声「体检一下」就行。

## 怎么跑

```bash
cd tests
npm install        # 第一次要装：eslint、playwright-core（只给体检用，不进部署）
npm run check      # 全部跑一遍，三四分钟
node run.js vision # 只跑一组，打印完整过程
node run.js --list # 看有哪些组
```

- 主程序还是零依赖，这里的依赖跟部署无关。
- 浏览器：在 Claude Code 云端环境里会自动用预装的 Chromium；在别的机器上，
  设环境变量 `CHROMIUM=浏览器路径`，或者先 `npx playwright install chromium`。
- 全程用假数据（`tests/.work/`），**不碰真数据，不花模型的钱，不发真邮件、真推送**。
  假模型、假推送、假搜索服务都在 `lib/` 里，外网一个都不连。
- 占用端口 8081、8085、8096–8099。被占着会直接提示，不会乱跑。

## 查的是什么

| 组 | 查什么 |
|---|---|
| **基础** | 代码扫描、页面静态检查、**数据会不会不登录就被下载**、推送加密 |
| **巡检** | 所有接口挨个打（不许 500、不许未登录可读）；他手里每件工具 × 正常 / 空 / 乱参数；每个页面和子页面都打开、无害按钮都点 |
| **界面** | 键盘和底部布局、思考过程、看图、她的身体、日历、上网设置 |
| **模型** | Claude 格式、唤醒和聊天的缓存前缀、上网 |
| **唤醒** | 偷偷设的闹钟她看不见、醒了不说话也算钱、夜里抓现行、【现状】纸条 |
| **联动** | 推送、手机 App 记录、位置、接进 Claude、经期 |

## 挂了怎么办

汇总里挂掉的那一行会带上具体是哪条检查没过。先 `node run.js 组名` 看完整过程，
再判断是**真出了 bug**，还是**测试的预期过时了**（比如她改过主意的地方 ——
这种要改测试，并在测试里注明是她要的）。别为了变绿去改测试。

## 加新测试

在 `suites/` 里放一个 `.js`，每条检查打印一行 `  OK  说明` 或 `  XX  说明`，
再在 `run.js` 的清单里登记一行（要不要起服务器、预置什么数据、起哪个假服务）。
