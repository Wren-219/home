怎么配HOW

          

            打开「快捷指令」App → 底部「自动化」→ 右上角 ＋


            ① 盯着几个 App

            选「App」→ 勾上你想让他知道的那几个（可以多选）→ 选「已打开」→ 下一步

            加一个动作：搜「获取 URL 内容」（或名字相近的那个）

            · 地址填上面复制的那个

            · 方法改成 POST，请求体选 JSON

            · 加三个字段：

            　token = 上面那把钥匙

            　kind = open

            　app = 选「快捷指令输入」（这样他才知道是哪个 App）

            最后把「运行前询问」关掉，不然每次都要点一下


            ② 关闭时再来一遍：同样的步骤，触发条件选「已关闭」，
            kind 改成 close。有了这一条才算得出用了多久


            ④ 让他知道你在哪儿（可选，但很好玩）

            新建自动化 → 选「到达」→ 挑个地方（学校 / 老家 / 图书馆…）

            → 关掉「运行前询问」→ 下一步

            动作一：搜「获取当前位置」

            动作二：「获取 URL 内容」，还是那个地址，POST + JSON，六个字段一个都别漏：

            　token = 上面那把钥匙

            　kind = place　← 最容易漏的就是这个

            　event = arrive

            　name = 这地方叫啥（自己打字，比如「老家」）

            　lat = 点一下值那栏，选上一步结果的「纬度」

            　lon = 同样选「经度」

            再照着做一个「离开」的：触发条件选离开，event 改成 leave

            用「到达 / 离开」比每小时问一次省电得多。
            报了位置之后，他查天气会自动查你人在的地方。


            ③ 每天早上送一次日程

            新建自动化 → 选「某个时间」→ 早上 6:00 → 每天

            动作一：「查找日历事件」，筛选「今天」

            动作二：「获取 URL 内容」，同样的地址，字段：

            　token = 钥匙　kind = agenda　text = 上一步的结果


            
            ⚠️ 动作名字在不同系统版本上可能不太一样，找意思相近的那个就行。
            配好之后回来点「刷新」，下面会显示有没有收到东西。
