# 晤 · With You

自己的 AI 伙伴移动端网页：密码锁 + Home（天数 / 倒数日 / 日历 / 小票清单 / 日记 / 照片 / 信箱）+ Chat（DeepSeek）+ Memory + Settings。

## 部署到 Zeabur（推荐）

1. Zeabur 控制台 → **New Project**（或用现有项目）→ **Add Service → Git → 选择本仓库 `Wren-219/home`**
2. Zeabur 会识别出 Node 项目并用 `npm start` 启动，无需其他构建配置
3. 在服务的 **Environment Variables** 里添加：
   | 变量 | 值 | 说明 |
   |---|---|---|
   | `LLM_API_KEY` | `sk-...` | 必填，聊天模型 Key（旧名 `DEEPSEEK_API_KEY` 也认） |
   | `LLM_BASE_URL` | `https://api.deepseek.com` | 选填，聊天模型接口（OpenAI 风格均可） |
   | `LLM_MODEL` | `deepseek-chat` | 选填 |
   | `WORKER_API_KEY` | `AIza...` | 选填，后台杂务模型 Key（不配则共用聊天模型） |
   | `WORKER_BASE_URL` | `https://generativelanguage.googleapis.com/v1beta/openai` | 选填，例：Gemini 免费额度 |
   | `WORKER_MODEL` | `gemini-2.5-flash-lite` | 选填 |
   | `HISTORY_BUDGET` | `30000` | 选填，每轮送给模型的聊天历史额度（token）。超了一次砍掉三成（不是每轮挤掉一句），缓存才接得上 |
   | `WU_PIN` | `0527` | 选填，四位页面密码。**设了就以它为准**，忘记密码时用它找回；不设则用服务器上 `data/auth.json` 里的（默认 0527，可在设置页里改） |
   | `WU_TZ_OFFSET` | `8` | 选填，你所在的时区（东八区是 8）。容器默认跑在 UTC，不设这个晤会把你晚上十点说的话当成下午两点 |

   聊天（晤的"嘴"）与后台杂务（记忆蒸馏、dream 整理）可用不同模型：
   贵的好模型聊天，便宜/免费模型干活。
4. **Networking → Generate Domain** 生成一个 `xxx.zeabur.app` 域名
5. iPhone Safari 打开这个域名 → 分享 → **添加到主屏幕** → 从主屏幕打开即是全屏 App（已适配灵动岛安全区）

## 备份与搬家（重要）

所有数据只存在服务器的 `/app/data`（Zeabur Volume）里。**服务停掉、Volume 删掉，数据就没了。**

- **备份**：设置 → 备份与搬家 → 「下载全部」，得到一个 JSON 文件。
  里面含日记 / 信 / 聊天记录 / 记忆 / 长期文件 / 人设 / 照片 / API 配置 / 密码。
  ⚠️ **含明文 API Key 与密码，请当密码文件保管。**
- **搬到新地方**（大约十分钟）：
  1. 任意平台新建服务，Git 接这个仓库，`npm start` 启动，Node 18+
  2. 挂一个 Volume 到 `/app/data`（不挂也能跑，但重启会丢数据）
  3. 环境变量至少给 `LLM_API_KEY`（其余可后续在界面里配）
  4. 打开新域名 → 输 `0527` → 设置 → 备份与搬家 → 「恢复」→ 选那个 JSON
  5. 恢复后**用备份那天的密码**重新登录一次，就全回来了

## 本地运行

```bash
DEEPSEEK_API_KEY=sk-xxx node server.js
# 打开 http://localhost:8080
```

不配 Key 也能跑：聊天会退回演示回复，其余功能不受影响。

## 已实现

- 页面密码（默认 0527，可在设置里修改）。**密码由服务器验证**：日记 / 信 / 聊天
  记录 / 照片 / 记忆这些接口，没登录一律 401，上传的文件也一样。登录后拿一个
  一年期的 HttpOnly cookie；改密码会让其他设备上的旧登录立刻失效
- 清单 / 倒数日 / 日记 / 信箱 / 照片 / 聊天记录存在服务器（`/app/data`），
  localStorage 作离线兜底
- 记忆系统：遗忘曲线 / 回忆强化 / 情绪打标 / dream 整理。**跟聊天连不连有个开关**（记忆页顶上，默认断开）：
  断开时不自动蒸馏聊天、不把卡片塞给他、屋里也不给他 `remember`，人设里那句「系统会在【你的记忆】里…」也拿掉；
  卡片、手动记一笔、Claude 那边的 recall / remember 都照旧
- 长期文件（手机「记忆 → 长期文件」，或 `/admin` → 长期文件）：**常驻**文件每轮完整注入，
  排在稳定前缀里吃满缓存；**备查**文件不占每轮额度，晤用 `list_docs` / `read_doc` 按需去翻。
  支持导入 `.txt` / `.md` / `.json` / `.docx`（docx 用 Node 自带 zlib 解压后抠正文，无第三方依赖）
- 晤的人设可在界面上编辑（存 `data/persona.json`，清空即恢复代码里的默认值）
- 上下文按 token 额度截断而不是固定条数，设置页能看到"这个窗口装了百分之几"
- **多聊天窗口**：可新建 / 改名 / 封存（只读）/ 删除；晤的八维状态只绑定一个窗口
  （`data/windows.json` 的 `bound`，只有该窗口的对话会推动驱动值），
  记忆 / 长期文件 / 人设所有窗口共用
- 消息：距上一条超过 30 分钟自动插时间条；长按弹出贴着该条消息的玻璃浮窗
  （看发送时间 / 改了重发 / 让晤重说一次 / 复制 / 删除）
- **MCP 外部服务**（设置 → 外部服务）：server.js 内置 MCP 客户端
  （JSON-RPC over HTTP，支持 JSON 与 SSE 两种响应，带 `Mcp-Session-Id`），
  填地址 + 令牌 → 「连一下」抓工具清单并**存盘** → 开关打开后工具以
  `服务名__工具名` 并入晤的工具箱。清单不每轮抓取，保证缓存前缀稳定
- **晤会主动找你**：聊天中他可以给自己记一个时间点（「她说回家再说」），到点服务器把他叫醒，
  让他重读一遍对话再决定要不要开口 —— 沉默是默认答案。这些闹钟对你是隐形的，
  界面上看不到，他也不会在回复里提起。开口之前要过一道勿扰门：你在上课 / 夜里 /
  刚跟他聊完 / 他今天已经说过话了，都会往后顺延而不是作废。
  **你亲口让他叫你**（「五分钟后喊我」「七点叫我」）的那种不一样：他设的时候标上 `asked`，
  到点就叫，不过那道门，也不占他一天主动开口的次数。闹钟每分钟看一次，快到点的掐着点醒。
  他醒来说的话，你开着 app 时二十秒内就会冒出来（`GET /api/chat/fresh`），
  而且在你手上那份拿到之前，你这边保存聊天不会把它冲掉
  课表与勿扰在「设置 → 你的时间」里填，课表一行一节：`周一 08:00-09:40 高等数学`。
  唤醒请求带的是跟聊天**逐字相同**的一份工具（`chatTools()` 唯一出口），
  两边都不设 `tool_choice` —— 工具排在缓存前缀最前面（tools → system → messages），
  差一个字节整条前缀就废了。他醒来也能先查一眼（手机、位置、天气、上网）再决定说什么，
  最多两轮
- **手机联动**（设置 → 手机联动）：用 iPhone 自带的「快捷指令」把两件事递给服务器 ——
  ①每天早上从日历读一份今天的日程（进【现状】，他每轮都知道）
  ②你挑的那几个 App 什么时候被打开 / 关上（存三天，他用 `check_phone` 按需查，
  不是每次都通知你）。走 `POST /api/ping`，带一把只能写不能读的独立钥匙
  （快捷指令带不了登录 cookie），钥匙在界面上随时能换
- **接进 Claude**（设置 → 接进 Claude）：server.js 自带 MCP **服务端**
  （Streamable HTTP，`POST /mcp/<钥匙>`），把 14 件工具借给 Claude 官方 app 里的他 ——
  查手机、查位置、查天气、查经期、看此刻、翻日记和信、翻长期文件、
  检索与写入记忆、往外寄信，还能借她那台服务器去读一个网页
  （国内的站从那儿走得通）。
  钥匙写在路径里（Claude 添加连接器时只能填一个网址），**能读日记和聊天记录，别外传**；
  在界面上随时能换一把。钥匙不对一律回 404，不暴露这个端点的存在
- **寄信**（设置 → 写信出去）：手写的 SMTP（零依赖，走 465 的 SMTPS），
  配好邮箱和授权码，晤就能用 `send_mail` 往外寄信。
  可以打开「他主动找我时顺手寄一封」—— 手机的邮件提醒就是现成的推送，
  省掉整套 Service Worker。授权码只进不出，界面上永远只显示「已存」
- **声音**（设置 → 声音）：借 ElevenLabs 用她们做的那个声音。他有 `send_voice`（发语音）和
  `call_her`（打电话）两件工具，唤醒时 JSON 里也能 `voice: true` / `call: true`；
  她按住🎙说话（Scribe 听写成字给他），右上角电话按钮打给他。通话是一来一回的：
  前端听出她说完了（音量 + 静 0.9 秒）→ `/api/call/turn` 听写、交给他（跟聊天同一个 `prepTurn()`
  前缀）、分句念、按顺序推回。念的时候跳过括号里的动作。每天有念字上限。
  钥匙只进不出，也能走 `WU_ELEVEN_KEY` / `WU_ELEVEN_VOICE`
- **前情提要**：一个窗口没压缩过的聊天到了额度九成，他（聊天那个模型、带着人设）在后台把老的八成
  用自己的口吻写成一段前情提要，留最近两成原话；之后再到九成，旧提要 + 新的一段滚动成新提要（上限约 1500 字）。
  提要排在稳定前缀里，只在压缩那一下变。聊天页窗口菜单 →「前情提要」能看、能改、能删掉这版让他重写；
  聊天里压到哪儿有一道线
- **这个月**（设置页最上面）：本月已花、每天一根小柱子、按现在的速度月底大约多少；预算可以不设（只看不管）、
  按预测定、或者手填。定了预算又花到了，他就先不主动找你（聊天照常，你让他叫的闹钟照常）。
  钱是代码算的（token × 价格，不经过 AI），**记账那一刻就算好存下**：以后改价格、换模型都不动已经算好的。
  价格可以分高峰时段（时段、倍数、周末算不算），记账时正好在高峰就按倍数算。还没填价格时的用量先攒着，
  第一次填价格时补算一次。环境变量那套的价格也在这张卡上填
- **他的眼睛**（设置 → 模型与花费 → 看图用）：看不了图的聊天模型（DS）靠一个便宜 / 免费的看图模型把图片读成一段文字。
  她发的照片上传后就先读好（`data/imgdesc.json`，一张只读一次），聊天时他收到的是「（图片内容：…）」
- **看一眼她的屏幕**（设置 → 你的时间，默认关）：他醒着时调 `peek_screen` → 服务器给她的 iCloud 邮箱发一封带暗号的邮件 →
  她手机上的快捷指令自动截屏、POST 到 `/api/screen?token=` → 眼睛读成文字 → 他再醒一下决定说不说话。
  聊天里留一张「👀 他看了一眼你的屏幕」卡片（截图 + 他看到了什么）。一天有上限，截图只留最近 6 张
- **他记得自己看过**：看过屏幕后，聊天历史里留一句「（你看了一眼她的屏幕：…）」，写好就不再变，缓存接得上；截图本身不进历史。
  聊天模型自己能看图（比如 Claude）时，截图直接给他看，这句话用他自己写的（不找眼睛代读）
- **他想看看你**（工具 `ask_photo`）：聊天里出现「📷 他想看看你」卡片，你点「拍一张」才打开相机（前置镜头），拍完直接发给他；
  点「这会儿不方便」就收起。半小时内不会反复要
- **照片张数自己调**（设置 → 模型与花费）：最多留几张真图（默认 8）、超了一次换掉几张变文字（默认 6）
- **醒来做了什么**：他醒来查过什么（看了眼你在忙什么、查了下天气、记了件事…）在他那句话上面留一行小字，只报动作不报内容
- **她不回了，他追问一句**（设置 → 你的时间）：他每回完一句就记一笔，她 15 分钟（可改）还没回就醒一下，
  带着她手机上那几个 App 的动静，自己决定追不追、怎么追。一次不回只追一回，一天最多 4 次；上课、夜里睡着了、
  预算花到了都不追；不占「一天主动开口几次」的名额
- **自动备份**（设置 → 备份与搬家）：每 15 天，服务器在晚上十点把一份备份（.json 文件）当附件寄到「写信出去」里填的收件地址
  （没填就寄回发件邮箱）。不带照片（太大）、不带密码和各种 Key；拿它恢复不会清掉服务器上现有的 Key。
  「现在寄一份试试」能马上寄一份
- **猜密码限速**：同一个地方连错 5 次锁 5 分钟，锁过还接着错就翻倍（最长一天）；一小时里全部加起来错满 30 次，
  没登录过的一律先等半小时。已经登录过的手机（离开 5 分钟自动上锁再解锁）不受影响
- **缓存体检**（设置页，花费下面）：连着聊（上一轮在 5 分钟内）的最近几十轮缓存命中了多少。
  每轮跟上一轮比，开头变了就记下原因（到额度砍了一截、换掉一批旧图、改了人设、工具清单变了、删改了消息）；
  命中率低又说不出原因的那几轮标红 —— 多半是 bug 在白花钱
- **体检**（`tests/`）：41 组、将近六百条检查，全用假数据和假服务，不碰真数据、不花钱。
  定期跑一次就好：`cd tests && node run.js`（第一次要装依赖，命令见 `tests/README.md`；
  故意没放 `package.json`，免得部署平台把它当成要一起部署的东西）
- **静态文件只发白名单**：`/`、`/admin`、`/sw.js`、两张图标，别的一律 404。
  数据目录在 Zeabur 上是 `/app/data`，就在项目目录里 —— 以前的「有什么发什么」
  会让 `/data/*.json` 不用登录就能下载。新加公开文件要在 `PUBLIC_FILES` 里登记
- **看图**：聊天里发的照片，前端另传一份长边 1568px 的 JPEG 专门给他看（原图照样进相册）。
  服务端发给模型前才从 `/files/` 读出来转 base64：Claude 走 `image` 块，OpenAI 格式走
  `image_url` + data URL。每套 API 有「看得懂图片」开关 —— Claude 默认开，OpenAI 格式默认关
  （DeepSeek 看不了，发图会报错）；关着时他只收到「发来了 N 张照片（你这边看不到）」。
  历史里的真图最多 8 张，超了一次换掉 6 张变文字（都能在设置里调；不是每来一张挤掉一张），字节不变，缓存接得上；只认 `/files/` 下的文件名
- **真推送**（设置 → 推送）：零依赖手写的 Web Push。VAPID（RFC 8292，P-256 + ES256 JWT，
  签名必须是裸 r||s）+ 加密（RFC 8291，ECDH → HKDF → AES-128-GCM）+ 封装（RFC 8188）。
  HKDF 用 Node 内建的 `crypto.hkdfSync`，不自己写。`sw.js` 在根目录，由现成的静态路由托管。
  **iOS 的硬条件**：16.4+、先「添加到主屏幕」、从那个图标打开、授权由用户手势触发 ——
  缺一条都收不到，界面会逐条查清楚再告诉你缺哪条。
  推送失败只有 **410 Gone** 才立刻删订阅；404 连着三次才算，别的错不计数
- **上网**（设置 → 上网）：`web_search` + `read_web` 两件工具。搜索要借一家服务的门，
  支持 Tavily / Brave / 博查三家，挑一家注册把钥匙填进来（三家接口形状不同，
  服务端各拆各的，统一成「标题 / 摘要 / 链接」）。读网页不要钥匙 ——
  抓 HTML、砍脚本样式、还原实体、截 6000 字；要登录或靠 JS 后加载的页面读不到，
  他会说读不着而不是编。没配钥匙这两件工具就不进工具清单。
  钥匙也可以走环境变量 `WU_SEARCH_KEY` / `WU_SEARCH_VENDOR` ——
  前端打不开的时候（平台闹脾气、域名解析不了）照样能配上；界面上填过就以界面的为准
- **她的身体**（设置 → 她的身体）：记经期。周期和天数可以手填，留 0 就按她自己的
  记录算（只认相邻两次间隔 15–60 天的，免得记错或漏记把平均带偏）；记录不够时
  退回 28/5 并明说「是估的」。他那边只在完整版【现状】里收到**一句事实**
  （「她在经期第 3 天」），怎么接是他自己的事 —— 不给台词；
  外加 `check_period`、`period_log` 两件工具。
  「让他知道」一关，纸条和工具**同时**闭嘴，她自己照看不误。
  日历上也标：记过的实底色，往后三个周期虚线框
- 八维驱动引擎：随时间与对话涨落，影响晤的语气
- Chat 通过后端 `/api/chat` 流式转发，支持工具调用（写日记 / 加清单 / 写信…）
- **多套 API 配置**（设置 → 管理 API，或 `/admin` → API 与花费）：地址 / Key / 模型 /
  格式 / 价格一套一套存在服务器上，随时切换「聊天用哪套、干活用哪套」，不用重新部署。
  Key 只进不出，接口永远只回打码后的后四位；没选中的角色自动回落到环境变量那套
- **两种 API 格式**：`openai`（DeepSeek / 中转站 / 绝大多数）与 `anthropic`
  （Claude 官方，server.js 内置格式翻译，并显式打上 `cache_control` 缓存标记）
- **用量与花费**：每轮记录输入 / 输出 / 缓存命中的 token，按各套自填的价格算钱；
  设置页可开「每条消息显示用量」，`/admin` 有累计表与缓存命中率
- `/admin` 桌面管理台（同一个密码）
- PhotoStack 照片堆（github.com/Wren036/PhotoStack，PolyForm Noncommercial）
